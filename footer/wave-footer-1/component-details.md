## 14. FAQ

**Q1. Question**
```
Is the newsletter form connected to anything?
```
**Answer**
```
No. It validates the email and shows a fake success message. Replace the setTimeout in script.js with your API call (Mailchimp, ConvertKit, etc.).
```

**Q2. Question**
```
How do I change the wave colours?
```
**Answer**
```
Edit the fill values of .w1, .w2 and .w3 in style.css. Keep .w3 the same colour as the footer background.
```

**Q3. Question**
```
Does it work on mobile?
```
**Answer**
```
Yes. Columns become a tap-to-open accordion below 640px.
```
