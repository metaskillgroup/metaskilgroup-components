## 14. FAQ

**Q1. Question**
```
How do I add my own testimonials?
```
**Answer**
```
Edit the testimonials array at the top of script.js. Each entry has name, role, rating, source and text.
```

**Q2. Question**
```
Can I change the scroll speed?
```
**Answer**
```
Yes. In script.js the --duration value is set per row (60s + 12s per row). Lower numbers scroll faster.
```

**Q3. Question**
```
What if a user prefers reduced motion?
```
**Answer**
```
The marquee stops and each row becomes horizontally scrollable instead.
```
