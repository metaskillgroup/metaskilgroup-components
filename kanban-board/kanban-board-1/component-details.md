## 14. FAQ

**Q1. Question**
```
Does drag and drop work on phones?
```
**Answer**
```
Yes. Long-press a card for a moment, then drag it. A normal swipe still scrolls the board.
```

**Q2. Question**
```
Where is my data saved?
```
**Answer**
```
In your browser's localStorage, so tasks stay after a refresh. Use the Reset button to bring back the demo tasks.
```

**Q3. Question**
```
How do I add more columns?
```
**Answer**
```
Add an entry to the COLUMNS array at the top of script.js. Add a limit value to show a WIP warning.
```

**Q4. Question**
```
Does it use any library?
```
**Answer**
```
No. Drag and drop is written with pointer events in vanilla JavaScript.
```
