## 14. FAQ

**Q1. Question**
```
Does it work on touch devices?
```
**Answer**
```
Yes. It uses pointer events, so dragging a finger over a card tilts it, and a tap flips it.
```

**Q2. Question**
```
How do I change a card's colours?
```
**Answer**
```
Each card has --c1 and --c2 CSS variables in its style attribute. Change those two colours.
```

**Q3. Question**
```
Can I use my own images?
```
**Answer**
```
Yes. Replace the SVG inside .card-art with an img tag. Keep it inside the same container.
```
