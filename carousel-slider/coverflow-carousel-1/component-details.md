## 14. FAQ

**Q1. Question**
```
How do I add my own slides?
```
**Answer**
```
Edit the slides array in script.js. Each slide has a title, text details, a colour and a background gradient.
```

**Q2. Question**
```
Can I use real images instead of gradients?
```
**Answer**
```
Yes. Set art to something like url(poster.jpg) center / cover in the slides array.
```

**Q3. Question**
```
How do I change the autoplay speed?
```
**Answer**
```
Change AUTOPLAY_MS in script.js (5000 = 5 seconds).
```
