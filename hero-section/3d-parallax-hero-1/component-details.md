## 14. FAQ

**Q1. Question**
```
Are the laptop and phone images?
```
**Answer**
```
No. Both devices and the dashboard inside are built with CSS and inline SVG, so they stay sharp at any size.
```

**Q2. Question**
```
Does the tilt work on phones?
```
**Answer**
```
The mouse tilt only runs on devices with a fine pointer. On touch screens the mockup floats gently instead.
```

**Q3. Question**
```
How do I change the rotating words?
```
**Answer**
```
Edit the .word spans inside .rotator in index.html. Add or remove as many as you like.
```
